# TFG
Diseño en SolidWorks del Robotino 4, un robot omnidireccional de cuatro ruedas, con el objetivo de poder hacer una simulación realista en la última versión de Gazebo y conseguir que el robot se pueda mover de manera teleoperada en simulación, y estudiar con detalle el coeficiente de fricción de las ruedas omnidireccionales y modelar un buen controlador PID para cada una de las ruedas.
